# BYDV Aphid Pest Management Tool (Virginia)

Internal web application for exploring aphid pest management decisions related to Barley Yellow Dwarf Virus (BYDV) for Virginia farmers.

This repository primarily exists as a remote code backup and development workspace.

### Tech Stack:

- Vite
- React
- TypeScript

### Notes:

- Not intended as a general-purpose or public package
- Environment-specific configuration may be required at deployment time

### Development:

`
npm install
npm run dev
`
